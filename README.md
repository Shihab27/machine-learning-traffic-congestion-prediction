# Machine Learning-Based Traffic Congestion Prediction

## Overview

This project explores traffic congestion prediction using smart city transportation data and machine learning techniques. The study focuses on Los Angeles traffic patterns and investigates how directional traffic flow, temporal variables, and transportation analytics can support congestion forecasting and intelligent urban mobility planning.

The project includes:
- data preprocessing,
- feature engineering,
- exploratory data analysis,
- regression modeling,
- classification modeling,
- and traffic congestion prediction experiments.

---

## Research Objectives

The main objectives of this project are:

- Analyze traffic congestion patterns in Los Angeles
- Identify weekday and weekend traffic behavior
- Develop machine learning models for congestion prediction
- Compare regression and classification approaches
- Explore transportation analytics for smart city applications

---

## Dataset

The traffic dataset was collected from public smart city transportation sources including Los Angeles transportation data portals.

Main variables include:
- traffic volume,
- directional traffic flow,
- temporal variables,
- congestion indicators,
- and transportation-related features.

---

## Experimental Results

The experiments demonstrated strong predictive performance for traffic congestion analysis.

### Key Findings
- Linear Regression achieved strong prediction accuracy with high R² performance
- Random Forest classification achieved approximately 99% congestion classification accuracy
- Directional traffic flow patterns alone provided strong predictive capability even without total traffic volume features
- Temporal traffic variables improved congestion analysis
